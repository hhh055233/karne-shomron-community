# קרני + בורד
קרני: AI ציבורי למשתמשי הלוח.
בורד: AI פרטי למנהל הראשי בלבד.
בורד משתמש בכלי allowlist, עם תוכנית + בדיקות + אישור לפני שינויים מסוכנים. אין eval ואין shell חופשי.



## בורד קוד מאושר
בורד יכול לקרוא את קוד הפרויקט מ-GitHub, להכין תיקון באמצעות מנוע AI, להציג תוכנית ושינוי מוצע, ורק לאחר אישור מפורש `ברהב` לבצע Commit לקובץ המורשה ב-GitHub.

סודות נדרשים ב-Cloudflare Secrets: `GITHUB_TOKEN` ו-`OPENAI_API_KEY`. אין לשים אותם ב-HTML או ב-GitHub.
